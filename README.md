# SUARA-TI
SUARA TI adalah sebuah layanan aspirasi berbasis website yang dirancang khusus untuk menjadi jembatan komunikasi lingkup prodi yang terstruktur antara mahasiswa dan pihak prodi. Melalui website ini, mahasiswa dapat mengirimkan keluhan, kritik, maupun saran dengan mudah dalam satu pintu.

Website ini ditujukan khusus bagi mahasiswa aktif Program Studi Teknik Informatika. Ketentuan ini diterapkan untuk memastikan bahwa aspirasi yang disampaikan berasal dari mahasiswa yang sedang menjalani proses akademik dan aktivitas di lingkungan kampus. Dengan demikian, masyarakat umum, alumni, maupun mahasiswa dari program studi lain tidak memiliki akses untuk menyampaikan aspirasi pada platform ini. Untuk mendukung verifikasi tersebut, data pengguna akan disinkronisasikan secara langsung dengan data pada platform eSemesta.

## Implementasi FR-04
### 1. Identifikasi Kode dan Deskripsi FR
Kode FR: FR-04

Nama Fitur: Pengiriman Aspirasi Mahasiswa

Deskripsi:
Sistem menyediakan fitur bagi mahasiswa untuk mengirimkan aspirasi dengan memilih kategori masalah, mengisi isi aspirasi, melampirkan foto atau file pendukung secara opsional, serta memilih visibilitas identitas (anonim atau tidak). Sebelum aspirasi disimpan, sistem akan melakukan validasi kelengkapan formulir. Jika aspirasi berhasil melewati pemeriksaan, sistem akan menyimpan data ke database dan menghasilkan ID unik yang dapat digunakan mahasiswa untuk melacak status aspirasi.
